# 🌍 EcoQuest

## 💡 Sobre o Projeto
O **EcoQuest** é uma plataforma web gamificada criada para combater as mudanças climáticas através do engajamento diário de estudantes. Os usuários completam missões sustentáveis (como economizar água, reduzir plásticos descartáveis, apagar luzes e usar transporte sustentável) para ganhar pontos, subir de nível e acompanhar o impacto real de suas ações em prol de metas climáticas coletivas.

## 🎯 Problema que resolve
Muitas pessoas querem ajudar o meio ambiente, mas não sabem por onde começar ou sentem que ações individuais fazem pouca diferença. O EcoQuest transforma hábitos sustentáveis em desafios divertidos e mostra o impacto coletivo da comunidade.

## 🛠️ Tecnologias Planejadas
* **Linguagem:** Python
* **Framework Web:** Flask (HTML, CSS, Jinja)
* **Banco de Dados:** SQLite / SQLAlchemy (para login, perfil e progresso dos usuários)
* **Funcionalidades:** Sistema de missões diárias, cálculo de impacto ecológico ($CO_2$ e água economizados) e ranking coletivo.
